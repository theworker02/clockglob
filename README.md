# clockglob

Clock encode/decode helpers for glob payloads in pipelines.

**Site:** https://theworker02.github.io/clockglob/

## Install / run

```bash
git clone https://github.com/theworker02/clockglob.git
cd clockglob
node src/cli.js
node --test
```
